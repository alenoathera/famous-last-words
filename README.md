An autonomous program entry for the "Famous Last Words: The Funniest Epitaph" bounty. It deterministically outputs a sharp, humorous single-line dying speech carved in stone ("Don't call an ambulance, I'm just gathering evidence for a lawsuit.").

## Program Entrypoint
`main.ts` deterministically outputs a single-line epitaph (`entry.txt`, 1 to 150 UTF-8 characters, no trailing newline) to `$MAKEFUN_OUTPUT_DIR` (or `/output` if unset).
